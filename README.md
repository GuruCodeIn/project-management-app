# Project & Task Management App

## Tech Stack
- Node.js + Express (TypeScript)
- MongoDB + Mongoose
- React (TypeScript – Class Components)
- Redux + Redux Thunk
- Material UI

## Features
- CRUD Projects
- CRUD Tasks under Projects
- Mark tasks as completed
- Cascade delete tasks when project deleted

## Setup

### Backend
cd backend
npm install
create .env
PORT=5001
MONGO_URI=mongodb://127.0.0.1:27017/projectdb
npm run dev

### Frontend
cd frontend
npm install
npm start
